# Semantic HTML Profile Page

A personal profile webpage created using semantic HTML as part of my web development learning journey.

## About the Project

This project demonstrates how to structure a personal profile webpage using meaningful semantic HTML elements.

## Sections Included

- About Me
- Skills
- Profile
- Contact

## Technologies Used

- HTML5

## Key Concepts Practised

- Semantic HTML
- HTML document structure
- Headings and paragraphs
- Lists
- Links
- HTML attributes

## Purpose

This project was created to practise HTML fundamentals and build a strong foundation for my journey into full-stack web development.
